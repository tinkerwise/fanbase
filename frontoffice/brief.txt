LIVE DATA (client-side JS, MLB Stats API + RSS)
------------------------------------------------
All live data fetches happen in the browser after page load:

  The Moves (team page):
    GET https://statsapi.mlb.com/api/v1/transactions
    ?teamId={id}&startDate={-90d}&endDate={today}
    Classified as: sign / trade / DFA / release / claim / other

  Draft Room (team page, supplemental):
    GET https://statsapi.mlb.com/api/v1/draft/{SEASON}
    Filters by teamId, shows current season picks

  Payroll (team page, supplemental):
    GET https://statsapi.mlb.com/api/v1/teams/{id}/roster
    ?rosterType=40Man&hydrate=person(salary)
    Falls back to curated JSON data when API returns no salary data

  Salary Rankings (league page):
    Same roster/salary endpoint for all 30 teams
    KNOWN fallbacks hardcoded for major-market teams (Dodgers $320M, Mets $340M, Yankees $290M, etc.)

  Recent Transactions (league page):
    MLB /transactions last 14 days, filterable by team pill buttons

  News (team page + league page):
    Google News RSS via rss-proxy.php (PHP CORS proxy, same as fanbase)
    Team query: "{team name} front office" (configurable per team JSON)
    League query: "MLB front office GM fired hired baseball"

  League Activity (home sidebar):
    MLB /transactions filtered for executive keywords (GM/manager/VP/hired/fired)

  Payroll Snapshot (home sidebar):
    Fetches a subset of teams, shows compact salary list

DESIGN SYSTEM
-------------
CSS custom properties for team accent color (--accent, --accent-text, --accent-rgb, --accent-dim, --on-accent)
Same contrast algorithm as Fanbase: luminance-based auto-darkening/lightening
Dark/light theme toggle (localStorage key 'fo_theme')
Last-viewed team in localStorage ('fo_team', default: 110 = Orioles)
Mobile-first responsive grid, breakpoints at 900px and 600px
All Lucide icons inline SVG (no external dependency)
Matches Fanbase visual language (side nav, sticky header, card components)
